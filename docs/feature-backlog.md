# superset++ feature ideas

Saved from the September 20, 2026 discussion. These are ideas for later, not committed delivery dates.

- Move Previous copies out of the normal sidebar into a recoverable Backups view, and show workspace folder locations clearly.
- Add a Resume ticket summary of recent changes, checks and unfinished work.
- Search Jira tickets, pull requests, branches and workspaces from one place.
- Add a Ready for review action that runs configured checks and prepares a change summary and Jira-linked draft PR.
- Flag Jira/PR status mismatches and offer a reviewed update action.

## Shipped

- Attention inbox for agent input requests, failed checks on authored PRs and requested reviews, with filters and direct navigation.
- Show each active agent as an indented sidebar row under its workspace, with status and direct session navigation.
- Improve Files search with filename and content modes, path filters and navigation to matching lines.
- Toggle Jira, Pull requests, Pages, workspace agent rows and file-content search in Settings.
